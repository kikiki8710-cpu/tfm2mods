# effects_lib — 강탈 궁 이펙트만 분리 보관 (2026-08-29)

`graft_effect.py` 로 사일러스 프레임에 **얹었던 이펙트만** 떼어 따로 모아둔 것.
나중에 다른 챔프·다른 애니에 재사용하기 위한 재료 창고다.

## 무엇이 들어 있나

| 항목 | 내용 |
|---|---|
| `<champ>__<anim>.png` | ★**이펙트만** 있는 가로 스트립(캐릭터 없음). 프레임 N개가 같은 폭으로 이어짐 |
| `_pre_graft/<champ>__<anim>.png` | 이펙트를 얹기 **직전** 상태(사일러스 캐릭터만). `gpt_out\*.bak_graft` 사본 |
| `_manifest.json` | 종별 메타 — 프레임 수 · 프레임 규격 · 확장 패딩 · 이펙트 픽셀 수 |
| `_contact.png` | 45종 한눈에 보는 컨택트 시트(각 종의 최다 픽셀 프레임) |

**45종.** `inquisitor__ult` · `inquisitor__ult_dash` 2건은 차분이 0px 이라 제외
(이펙트를 얹지 않고 백업만 남은 것).

## 어떻게 만들었나 (재현 가능)

```
이펙트 = gpt_out\<f>.png  −  gpt_out\<f>.png.bak_graft
```
`graft_effect.py` 는 이펙트를 얹을 때 프레임을 **대칭 확장**하는 경우가 있어(47종 중 20종),
그만큼 오프셋을 맞춰 차분했다:
```
FW,FH  = bak 프레임 규격      NFW,NFH = 최종 프레임 규격
padx,pady = ((NFW-FW)//2, (NFH-FH)//2)
최종 픽셀이 (그 자리의 bak 픽셀)과 다르면 → 이펙트
```

## 어떻게 다시 쓰나

이펙트 스트립은 **프레임 중앙 기준**으로 그려져 있다(게임이 프레임 중앙에 앵커를 둔다).
다른 캐릭터 프레임에 얹을 때는 중앙을 맞춰 합성하면 된다.

⚠**합성할 때 마스크 인자를 어떻게 줄지 주의.** 기존 내용 **위에 얹는** 것이므로
`dst.paste(eff, pos, eff)` 가 맞다. 반대로 **빈 캔버스에 배치**할 때 마스크를 주면
알파가 두 번 곱해져 `새α = α²/255` 로 흐려진다(2026-08-29 실사고 — `03_시행착오.md` 참조).

## 왜 남겨두나

이펙트 추출은 챔프마다 통하는 방법이 달라 **한 번 성공시키는 데 시행착오가 크다**
(팔레트 차집합 / 연결 성분 / 빈 띠 위쪽 / 채도 bbox 밖 / 빈도 — `auto_graft.py` 판정표).
성공한 결과를 버리면 그 탐색을 다시 해야 한다.
