# 선수(챔피언)별 판단 AI 오버라이드 — players/ 폴더 사용법
#
# 이 폴더에 "<선수>_<챔피언>.cfg" 파일을 두면, 그 챔피언에게만 해당 판단수치가 적용됩니다.
# (경기 중 다른 챔피언·백그라운드 시뮬에는 전혀 간섭하지 않음 — self 엔티티 기준으로만 적용)
#
# ── 파일 형식 (BOM 없는 UTF-8) ──
#   __champion = <챔피언키>      ← 필수. 이 값이 게임의 champion_name 과 일치해야 매칭됨.
#   __player   = <선수이름>       ← 선택(사람용 메모, 판단엔 무영향).
#   <노브키> = <값>              ← tfm2_ai_adjust.cfg 와 동일한 키. 여기 적은 것만 이 챔프에 오버라이드.
#
# 예)  Faker_아리.cfg
#   __champion = Champion_Ahri
#   __player   = Faker
#   numbers_threat = 80
#   tower_threat   = 60
#   stat_influence = 50
#
# 적지 않은 노브는 전역(tfm2_ai_adjust.cfg)/클래스 설정을 그대로 따릅니다.
# 우선순위: 선수(챔피언)별  >  클래스별(_class_)  >  전역.
#
# ── __champion 에 넣을 정확한 챔피언키 알아내는 법 ──
#   1) tfm2_ai_adjust.cfg 에 champ_verify = 1 (이미 켜둠)
#   2) 아무 경기나 시뮬 1회 → 모드폴더에 champ_verify.txt 생성됨
#   3) 그 파일의 "[경기서 탐지된 챔프]" 목록에 나오는 이름 = 그대로 __champion 값으로 사용
#   4) players/ 에 파일 만들고 다시 시뮬 → champ_verify.txt 의 idx≥0 + 적용횟수>0 이면 적용 확인
#   5) 확인 끝나면 champ_verify = 0 으로 되돌리기
#
# ※ 파일 확장자는 반드시 .cfg. 이 .txt 나 __로 시작하는 키는 로더가 무시.
# ※ 값은 실시간 핫리로드(파일 저장 후 ~1초). 경기 시작 시점의 값으로 판단됨.
