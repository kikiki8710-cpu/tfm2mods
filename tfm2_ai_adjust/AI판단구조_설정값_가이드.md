# TFM2 판단 AI 구조 & ai_adjust 설정값 가이드

> 기준 버전 **0.5.3** (2026-08-02 작성). 정본 = `SUBPLAN_동작_전수조사.md`(플랜별 상세) + `ANA\subplan별-튜닝레버-분류.md`(키 분류).
> 이 문서는 "게임 AI가 어떤 계층으로 판단하고, 각 설정값이 그 계층의 어디를 조절하며, 값을 올리고 내리면 어떤 효과가 나는지"를 순서도 중심으로 정리한 안내서.

## 1. 전체 판단 계층 (위→아래 순서도)

```
[매 AI tick, 선수(챔피언) 1명마다]
│
├─ ① 상위: subplan 전이엔진 (매크로 AI — "지금 어떤 국면인가")
│   │  phase(경기 국면: 에픽/세르펜/넥수비/넥공/패시브/범용255)를 보고
│   │  이번 tick에 수행할 "행동플랜(subplan, disc 번호 0~19)"을 결정
│   │
│   ├─ generic_build 운영전환 (로밍/합류/압박 등 매크로 오더)
│   │     └─ 설정: gb_* (byte-patch, gb_enable=1 필요)
│   ├─ CAND_FILTER 후보필터 (판단력 스탯이 난수 흔들림 폭 결정
│   │     — 판단력 100이면 결정적, 낮으면 후보 선택이 흔들림)
│   └─ reactive demote (위기 상황이면 강제로 수비 플랜 강등)
│
├─ ② 중간: movepri 디스패처 ("정해진 플랜을 어떻게 움직임으로")
│   │  disc 번호별 핸들러로 분기 → 각 플랜이 행동번호(code) 산출
│   │  ※ disc18(넥공격)/disc19(넥방어)는 별도 디스패처 소속(번호공간 다름)
│   │
│   └─ 각 subplan 판정 (아래 §3 — 설정값 대부분이 여기 소속)
│
├─ ③ 공통 필터 (모든 플랜 판정에 가로로 걸리는 층)
│   ├─ sv_* 공유 위협 severity 사다리 (위협이 유의미한가 필터, 29곳 일괄)
│   ├─ vis_window 시야 기억창 (사라진 적을 몇 tick 더 "아는 적" 취급하나
│   │     — 13개 판단에 한꺼번에 영향)
│   └─ apply_numbers_sp ★모드 신규 후퇴층 (게임 원본에 없음):
│         전력회피(numbers_*) + 포탑회피(tower_*) + 성향보정(stat_influence)
│         → "물러나야 함" 판정 시 행동번호를 7(후퇴/대기)로 강제
│
└─ ④ 별도 축: 귀환 점수 (fc59a0) — "지금 귀환이 이득인가" 점수 계산
      └─ 설정: rc_* 전부 + t_recall (recall_repl=1로 대체 중)
```

### 행동번호(code) 의미 (플랜의 출력)
| code | 의미 |
|---|---|
| 2 | 제자리/후퇴(이동 유지·물러남) |
| 4 | 붙어서 공격(교전/합류) |
| 6 | 스킬 시전류 |
| 7 | 멈춰서 대기/귀환(후퇴 강제의 목적지) |
| 8 | 그 자리 잔류 |
| 0xb~0x15 | 오브젝트 견제·재배치·전진 등 세부 |

## 2. 상위 게이트(공통 계층) 설정값

### 2-1. generic_build 운영전환 — `gb_*` (byte-patch · `gb_enable=1` 필요, 값 -1=원본유지)
"어느 국면으로 갈지"를 고르는 매크로 판단의 원본 상수를 직접 수정. 0.5.3 적용 자리 = 9곳(`gb_imm.txt applied=N/9`).

| 설정값 | 기본(원본) | 조절 대상 | 효과 |
|---|---|---|---|
| `gb_join_dist` | 60000 | 합류 판정 거리(지배 조건) | ↑=더 멀어도 합류 모드 |
| `gb_scout_radius` | 120000 | 거점/타겟 후보수집 반경(로밍 범위) | ↑=더 넓게 로밍 |
| `gb_close_radius` | ≈387 | 근접 판정 | |
| `gb_line_range` | ≈500 | 라인 판정 | |
| `gb_op_phase` | 31 | 운영 시작 시점(경기진행 카운터) | ↓=운영 일찍 시작 |
| `gb_push_hp` | 30 | 라인 대상 체력% 미만이면 압박 오더 | ↑=더 일찍 압박 |
| ~~`gb_join_phase`~~ | — | ⛔死 — 0.5.2부터 합류는 시간대 무관·거리만 |
| `gb_reach_cap` / `gb_reach_margin` | ≈140052 / 25000 | ⚠**전 AI 공유 사거리 헬퍼** — 켜면 모든 판단의 사거리에 영향. 기본 -1 무개입 권장 |

### 2-2. 공유 위협 severity 사다리 — `sv_*` (byte-patch · `sv_enable=1` 필요, 기본 0)
게임 AI 전체가 공유하는 "이 위협이 유의미한가" 필터. 같은 판정이 코드에 4벌(위협평가 정본함수·넥서스 공방·라인/정글 필터·타겟선택 점수) 복사돼 있고 29곳을 일괄 수정. **가장 파급이 큰 단일 레버군.**

```
위협비율 = 위협 × 100 ÷ 현재체력
심각 판정: 비율>sv_tr0
        또는 (체력%<sv_hp1 & 비율>sv_tr1)
        또는 (체력%<sv_hp2 & 비율>sv_tr2)
        또는 (체력%<sv_hp3 & 비율>sv_tr3)
'사소' 판정된 위협은 1/2^sv_discount_shift 로 깎고 상한 sv_discount_cap
```

| 설정값 | 기본 | 효과 |
|---|---|---|
| `sv_tr0~3` | 49/29/17/9 | 위협 문턱 — **↓=겁쟁이(작은 위협도 회피), ↑=대담** |
| `sv_hp1~3` | 65/40/25 | 체력 단계 경계 (낮은 체력일수록 낮은 문턱 적용) |
| `sv_discount_shift`·`cap` | 2·18 | 사소 위협의 반영 축소율/상한 |

### 2-3. 모드 신규 후퇴층 (게임 원본에 없던 판단 — 0이면 원본 동작)
플랜 판정 **뒤에** 얹혀서, 조건 만족 시 행동번호를 7(후퇴)로 강제.

| 설정값 | 기본 | 어디를 | 효과 |
|---|---|---|---|
| `tower_threat` | 200 | 적 포탑 사거리(`tower_range`=200000) 안에서 전력승산(근처 양팀 ΣHP×Σ공격 비교, 100=호각)이 이 값 미만이면 후퇴 | ↑=포탑 근처에서 더 잘 뺌. 0=미적용 |
| `tower_dps` | 8000 | 아군 포탑 딜을 아군 전력에 반영하는 힘(8000≈챔프 1명분, `ally_tower_dps>0`일 때) | ↑=아군 포탑 아래서 더 버팀 |
| `numbers_threat` | 49 | **한타** 전력승산 임계(반경 `numbers_range`=150000) | ↑=불리하면 더 잘 뺌 |

| `ally_tower_hp`/`ally_tower_dps` | 50/50 | 아군 포탑 HP·딜 가중치 | |
| `numbers_threat_sp0~17` | -1 | **플랜별 개별 임계**(-1=한타값 / 0=그 판단선 후퇴 안 함 / N=개별값) | 특정 플랜만 겁쟁이/대담하게 |

> ★**어디를 만져야 효과가 큰가** (인게임 실측 1경기, 07-31 — 후퇴 발동 횟수): **sp0 = 38,060(라인전 주력·압도적 1위)** > sp14=2,395(모르가드 견제) > sp12=1,660(모르가드 교전) > sp17=853(세르펜 견제) > sp1=540 > sp16=524(세르펜 사냥) > sp8=448 > sp10=48. 나머지는 발동 0회. **라인전 성향을 바꾸려면 sp3이 아니라 sp0**(코드가 disc를 3으로 고정해 넘기던 시절의 잔재 — 07-31 sp0/sp1 부활 수정).
> ⚠sp16/17은 07-30 감사에서 死레버로 오판된 적 있음 — **접두 파싱 키라 스캔 도구에 안 잡혔을 뿐, 실측 발동 확인된 LIVE 키**(07-31 정정). 발동 측정 = `sp_seen=1` → `sp_seen.txt`.
| `stat_influence` | 25 | 위 후퇴판단에 챔프 성향(공격성/에고/판단력) 반영 강도. 0=off | 공격성↑=덜 후퇴, 에고↑=덜 빠짐, 판단력↓=결정론적 오판 노이즈 |

## 3. Subplan별 판정 구조와 설정값

### 플랜 0/1/3 — LineAttack 계열: 라인 이동 판정기 (셋이 같은 코드) — `dd7_repl=1` 작동 중

```
플래그 켜짐? ──예──▶ 7 (대기)
   │아니오
초반: 두 플래그 조건 맞음? ──예──▶ 6 또는 4
   │아니오
합류 검사 (항상 진입)
   │  근처 적 수 ≥ dd_cover_count ?
   │     └ 예 → 병력비율 < dd_ratio_thr ? → 4(합류) : 7
전선 후퇴 판정
   │  내라인진척 = 아군진척 × dd_frontier_mult × 100 ÷ aggr_lane
   │  여유 = max(0, 적진척 − 내라인진척) < 현재시점 ? ──▶ 2 (물러남)
   │아니오
교전 후반 단계: 생존자·거리·슬롯 조합 ──▶ 2 / 6 / 7
```

| 설정값 | 어디를 | 효과 |
|---|---|---|
| `dd_frontier_mult` (350) | 전선 후퇴식 배수 | **↑=더 잘 물러남** |
| `aggr_lane` (100) | 전선 후퇴식 나눗셈 | **↑=덜 물러남** |
| `dd_cover_count` (0)·`dd_ratio_thr` (31) | 합류 발생 조건 (cover_count=0이면 합류 검사 사실상 항상 성립) | |
| `dd_facet_thr` (999) | 합류 시 4↔7 (기본 999라 안 걸림) | |
| `dd_near_dist`·`dd_gatee_dist`·`dd_f22e80_margin` | 후반 거리·생존자 (near_dist는 후반 단계 소관 = 부분 반영) | |
| `dd_ivar2_thr`·`dd_n_thr`·`dd_survivor_thr` | 후반 분기 | |
| `dd_lane_margin` (600) | 합류 검사의 적 카운트 창 | |
| ~~`dd_early_p3_thr`·`dd_cover_p3_thr`~~ | ⛔死 — 원본에 대응 조건 없음 | |

### 플랜 7 — Recall: 귀환 (두 층)

**(가) 귀환 이동 판단** — `d7_repl=1` 작동 중 (0.5.3에서 396/400 DIFF=0 검증)
```
안전 박스 안 + 부상 ──▶ 7 (즉시 귀환)
목표까지 d7_wp_dist2 안 → 버티는시간 = 체력×1000 ÷ 초당피해합 > 기준 ──▶ 8 (잔류)
체력% ≥ 기준 ? 8 : 7    (기준 = 자가회복 있으면 d7_hp_selfheal(21), 없으면 d7_hp_normal(41))
```

**(나) 귀환 점수 계산** — `recall_repl=1` 작동 중 (rc_* 전부 여기 소속)
```
배율 시작 = rc_u21_init(-30)
+ 가까운 적 체력% 낮을수록 가산: rc_ehp_t1(80)/t2(60)/t3(40) 구간별 rc_ehp_v1(90)/v2(80)
± 귀환지점→적 거리: 없으면 +rc_norp_bonus(200);
    rc_ed_near(150000)/mid/far 구간별 −rc_ed_near_pen(60) / +far_bonus(20) / +vfar_bonus(40)
± 아군 체력%: rc_ahp_t1(70)/t2(50) 기준 +rc_u13_bonus(10) 또는 −rc_ahp2_pen(30)
± 아군→적 거리: rc_ad_near(80000)/mid 구간 +rc_ad_near_bonus(15) 또는 −rc_ad_far_pen(25)
+ 수적 열세면 +rc_mult_bonus(100)
[선택] rc_join_weight(25)≠0이면: 합류점수 계산 → 배율 = max(체력기반, 합류기반)
최종점수 = 난수 × 배율 ÷ rc_score_div(100) + t_recall(1)
점수 > 기준값 ──▶ 귀환
```

| 설정값 | 효과 |
|---|---|
| `rc_ehp_*` ↑ | 적이 다쳤을 때 귀환 성향 ↑ (여유 있을 때 정비) |
| `rc_ed_near_pen` ↑ | 적이 가까우면 귀환 억제 강화 |
| `rc_join_weight` (25, **모드 신규**) | 체력 멀쩡해도 합류 이득 크면 복귀. 0=원본과 완전 동일 |
| `rc_join_adv/rescue/dnear/dmid/obj_mult` | 합류 이득 세부(우세·구조·거리·오브젝트 가중) |
| `rc_rng_a_base/spread_div/center`·`rc_score_div` | 난수 정규화 기준값 |

### 플랜 9 — Battle: 견제 유효성 판정 — ⚠`poke_repl=0` (현재 게임 원본이 돎)

