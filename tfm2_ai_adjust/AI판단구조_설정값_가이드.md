## §1. 판단 계층 (위 → 아래)

```
[매 AI 틱, 챔피언 1명마다]
│
├─ ① 플랜 결정기 — "지금 이 챔피언은 어떤 판단을 할 것인가"(= plan 번호 확정)
│     · 최상위 갈림 = 팀 모드(넥서스 공격/방어 등) → 16·17을 배타적으로 결정
│     · 그 아래 = 역할(정글러 여부)·오브젝티브 페이즈·전술 → 7·10·12·14
│     · 특수 = 채팅 이벤트(갱 요청/수락) → 2·9·10
│     · 나머지 = 기본값 0
│
├─ ② 플랜 실행 (아래 §3) — 각 플랜이 조건을 따져 행동 코드 산출
│     └ 모드가 여기를 후킹해서 대체(*_repl 스위치)하거나 원본 상수를 고침(byte-patch)
│
├─ ③ 공통층 (모든 판단에 가로로 걸림)
│     · 위협 민감도 sv_* / 시야 기억 vis_window·vw_* / 매크로 운영 gb_*
│     · ★모드 신규 후퇴층 — 전력·포탑 회피(numbers_*·tower_*·stat_influence)
│
└─ ④ 별도 축 — 귀환 점수 계산(rc_*)
```

**행동 코드**: `2`=제자리·후퇴 · `4`=붙어 공격 · `6`=스킬/귀환류 · `7`=대기·귀환 · `8`=잔류 · `0xb~0x15`=오브젝트 견제·재배치 등

## §3. 플랜별 — 발화 조건 · 설정값 · 효과

### 플랜 0·1 — 라인전 ★실측 1위 (`dd7_repl=1`로 모드가 완전 대체 중)

**언제 발화하나**: 특수 플랜(넥서스·에픽·갱 등) 조건에 안 걸리는 기본 상태 = 대부분의 시간.

**판단 흐름**
```
① 특정 플래그 → 대기(7) 즉시 종료
② 다른 플래그 조합 → 귀환(6) 또는 전면(4)
③ [봇 라인 커버] 아래가 모두 참일 때만:
     내 라인이 BOT · 오브젝티브가 이 라인을 지목 안 함
     · 시간창을 아직 안 넘김           ← dd_frontier_mult(30) / aggr_lane
     · 내 역할이 봇 듀오               ← dd_cover_role_min(3) 🆕
     · 듀오 파트너가 아군 진영 안
     · 라인 안 적 수 ≥ 2               ← dd_cover_count(2) / dd_lane_margin(120)
   → 내 체력% < 51 이면 (진척≥1000 ? 대기7 : 전면4) 아니면 전면4   ← dd_ratio_thr(51) / dd_facet_thr(999)
④ [메인] 근처 150000 안 적 스캔(안 보이거나 최근 목격이면 "적 있음")  ← dd_main_near_dist / dd_lane_margin
⑤ [라인 상태] 라인 활성 + 타깃 유효해야 계속, 아니면 라인공격(2)
⑥ [카운트] 아군 근접 수 vs 생존자 수                              ← dd_near_dist / dd_f22e80_margin
⑦ [거리 게이트 3종] 하나라도 걸리면 라인공격(2)                    ← dd_gatee_dist(170000)
⑧ [종단] 라인 진척 > 2 → 대기(7), 아니면 귀환(6)                   ← dd_ivar2_thr(2) / dd_survivor_thr(3)
```

| 설정값 | 원본 | 효과 |
|---|---|---|
| `dd_frontier_mult` | 30 | 커버 시간창 배수. ↑=커버 시간대가 짧아짐 |
| `aggr_lane` | 100 | 위 배수의 나눗셈(모드 합성값). ↑=덜 물러남 |
| `dd_cover_count` | 2 | 커버 발동 적 수. 0=상시 시도 |
| **`dd_ratio_thr`** | **51** | 커버 종단의 **내 체력%** 임계. ↑=조금만 다쳐도 물러남 |
| `dd_facet_thr` | 999 | 커버 종단 4↔7 갈림(기본 999라 거의 안 걸림) |
| `dd_lane_margin` | 120 | 사라진 적 기억 틱. ↑=오래 경계 |
| **`dd_cover_role_min`** 🆕 | **3** | 커버 참여 역할 하한. **2 = 미드까지 참여** / 5 = 커버 봉인 |
| `dd_near_dist`·`dd_main_near_dist` | 150000 | 아군/적 근접 판정 거리 |
| `dd_gatee_dist` | 170000 | 거리 게이트 E |
| `dd_ivar2_thr` | 2 | 종단 대기↔귀환 |
| `dd_survivor_thr` | 3 | 생존자 임계 |
| `dd_f22e80_margin` | 150000 | 생존자 카운트 반경 |
| ⚠`dd_n_thr` | 2 | **원본에 없는 게이트**(모드가 추가). 기본값 유지 권장 |
| ⛔`dd_early_p3_thr`·`dd_cover_p3_thr` | — | **死**(원본에 대응 조건 0개) |

### 플랜 7 — PassiveJungle (정글 · 라인개입)

**언제 발화하나**: 역할이 정글러 + 팀 모드가 넥서스 공수가 아닐 때.

**판단 흐름**: 팀전술 **초반 정글** 값을 매 틱 읽어 **세 갈래**로 분기 — 성장/커버 · **라인 개입** · 카운터 정글. 각 갈래마다 갱 발동 체력 문턱이 **독립 복사본**으로 존재합니다(= 갈래별 개별 튜닝 가능). 라인 개입 갈래는 적 로스터를 훑어 갱 대상 라인을 고르고 → **갱 셋업**(부쉬 대기 → 만료 → 취소 → 재시도).

| 설정값 | 원본 | 효과 |
|---|---|---|
| `gk_wait` | 10~15초 | 부쉬 대기 시간. **↑=한 자리에 오래 머묾(왕복 감소)** / ↓=빨리 포기 |
| `gk_hp_base_gank` | 70 | 갱 발동 체력 문턱(**라인 개입 갈래 전용**). ↑=갱 억제 |
| `gk_window_margin` | ×5 | 갱 윈도우 최소 여유. ↑=마감 임박 재시도 억제 |

> 배경: "정글이 부쉬에서 왕복한다"는 제보 → 이 갱 셋업 루프가 원인으로 특정됨. 위협 필터(`sv_*`)로는 잡히지 않습니다.

### 플랜 8 — ActiveRecall / 귀환

**판단 흐름**: 두 층으로 나뉩니다.
- **(가) 이동 판단**(`d7_repl=1`): 안전지대 안 + 부상 → 즉시 귀환 / 버티는 시간 계산 → 잔류 / 체력% 문턱
- **(나) 귀환 점수**(`recall_repl=1`): 적 체력·거리, 아군 체력·거리, 수적 우세를 더하고 빼서 배율을 만들고, 난수 한 번으로 점수를 뽑아 기준과 비교

## §6. 튜닝 전에 알아둘 함정 4가지

1. **대체된 함수 안의 byte-patch는 무효** — `vw_lane`이 그 사례. 모드가 완전 대체 중인 판단은 **재현측 키**(`dd_*` 등)로 조절해야 합니다.
2. **일부 키는 특정 팀전술에서만 작동** — `ec_*` 5키(오브젝트 빌드업 '스플릿' 전용)가 대표적. 값이 안 먹으면 전술부터 확인.
3. **값이 안 먹으면 그 판단이 아예 안 뜨는 것일 수 있음** — 발화 확인은 **`judge_dump=1`**(→ `match_log\`)로만. ⛔`sp_seen.txt`로 판정하면 안 됩니다(모드 처리 목록 밖 플랜은 카운터에 도달조차 못 하고, 후퇴 발동만 셉니다).
4. **byte-patch는 "설정했다 = 먹는다"가 아님** — 게임 폴더의 `*_imm.txt`에서 `applied=N/M`을 확인하세요(`sev_imm` 33/33 · `visshort_imm` 25/25 · `gank_imm` 14/14 · `obj_imm` 14/14 · `gb_imm` 9/9 · `d19_imm` 10/10 · `vis_imm` 1/1).
