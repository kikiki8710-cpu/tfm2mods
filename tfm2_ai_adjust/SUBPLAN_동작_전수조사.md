## §2. plan 0·1·3 — 라인전 (실측 1위 · 모드가 `dd7_repl`로 완전 대체)

게임 원본 함수 `passive_line`. 결과는 **대기(7) / 귀환(6) / 전면(4) / 라인공격(2)** 중 하나.

**판단 흐름 (평가 순서대로)**

```
① 특정 플래그가 켜져 있으면            → 대기(7) 즉시 종료
② 다른 플래그 조합이면 lane 기록 후    → 귀환(6) 또는 전면(4)
③ [봇 라인 커버 블록] — 아래 조건이 모두 참일 때만
     · 오브젝티브가 이 라인을 지목한 상태가 아님
     · 내 라인이 BOT
     · (게임모드·경과시간 창을 아직 안 넘김)          ← dd_frontier_mult
     · 내 역할이 봇 듀오                              ← dd_cover_role_min (신규)
     · 듀오 파트너가 아군 진영 안에 있음
     · 라인 회랑 안 + (보이거나 최근 목격) 적 수 ≥ 2   ← dd_cover_count / dd_lane_margin
   → 내 체력% < 51 이면 (진척 ≥ 1000 ? 대기7 : 전면4), 아니면 전면(4)   ← dd_ratio_thr / dd_facet_thr
④ [메인] 근처(150000) 적 5명 스캔 — 안 보이거나 최근 목격이면 "적 있음"  ← dd_main_near_dist / dd_lane_margin
⑤ [라인 상태 게이트] 라인이 활성이고 타깃·자기 참조가 유효해야 계속
⑥ [카운트] 아군 근접 수(150000) vs 생존자 수                          ← dd_near_dist / dd_f22e80_margin
⑦ [거리 게이트 3종] 넥서스-타깃 상대거리 / 근접수 ≥ 생존자수 / 앵커-타깃 < 170000 → 하나라도 걸리면 라인공격(2)  ← dd_gatee_dist
⑧ [종단] 라인 진척 > 2 이면 대기(7), 아니면 귀환(6)                    ← dd_ivar2_thr / dd_survivor_thr
```

## §3. plan 7 (PassiveJungle) — 정글 · 라인 개입

팀전술 **초반 정글**(성장·커버 / 라인 개입 / 카운터 정글) 값을 **매 틱 직접 읽어** 세 갈래로 갈립니다. 각 갈래마다 갱 발동 체력 문턱이 **독립 복사본**으로 존재합니다(= 갈래별 개별 튜닝 가능).

- 라인 개입 갈래 → 적 로스터를 훑어 갱 대상 라인 선정 → **갱 셋업**(부쉬 대기 → 만료 → 취소 → 재시도)
- 설정값 `gk_wait`(부쉬 대기 timeout·원본 10~15초) / `gk_hp_base_gank`(갱 발동 체력 문턱 70 — **라인 개입 갈래 전용**) / `gk_window_margin`(재시도 여유 ×5)
- 배경: 테스터 제보 "부쉬 왕복은 라인 개입 전술일 때만" → 이 경로가 원인으로 특정됨.
- ★**[2026-09-06 judge 계층] 게임 원본 핸들러(`old\passive_jungle.rs`, 0.5.8 `0xd2e500`)를 `src\judge\port\passive_jungle.rs` 로 재구현해 **shadow live**(`judge_live_passive_jungle=2`, 리플레이 321,350/321,350 DIFF=0). 이때 살아난 설정값 = `d7_hp_normal`(기본 41)·`d7_hp_selfheal`(기본 21)·`d7_wp_dist2`(기본 120000²). 동작(쉬운말): ①홈존 안이고 체력이 덜 찼으면 → 정글 안 감(5) ②배정 캠프 몬스터가 있고 캠프까지 거리² ≤ `d7_wp_dist2` 면 몬스터들의 초당 피해 합으로 "내가 버티는 시간 > 1초(tps)" 이면 → 캠프로(6) ③아니면 지속회복(스킬1·2의 회복량/흡혈) 여부를 보고, 몬스터에게 맞고 있지 않으면 **체력% ≥ (지속회복 있음 ? `d7_hp_selfheal` : `d7_hp_normal`)** 이면 캠프로(6) 아니면 5 ④맞고 있으면 다시 초당 피해로 판정. 몬스터 피해 = `[계수×공격력/100 + 기본값]`(×방어 보정, 관통·버프 반영) — 게임 콜리 0x12857f0 과 176,118건 교차검사 불일치 0. 캠프 위치는 게임과 같은 **스레드로컬 메모 캐시**를 읽는다(낡은 값도 게임과 동일하게).

## §8-2. 게임 원본의 결함 고치기 (편집기 「기타」 탭 · **전부 기본 꺼짐**)

플랜과 무관하게 **모든 판단이 공유하는 계산**에 있는 원본 결함을 선택적으로 고칩니다. 켜지 않으면 원본과 완전히 같습니다.

| 키 | 무엇이 잘못됐나 | 켜면 | 적용확인 |
|---|---|---|---|
| `fix_skill2_dmg` | AI가 자리 위험을 셀 때, **적의 스킬2만 스킬1 값으로 대신** 넣습니다(아군은 정상). ⟹ 스킬2가 강한 적을 덜 무서워합니다 | 스킬2 피해를 제대로 셉니다. 전체적으로 **조금 더 몸을 사림** | `fix_imm.txt` |
| `fix_hp_ratio` | 스킬 피해 = 고정값 + 공격력 비례 + **체력 비례**인데, AI 예측이 **체력 비례 항만 통째로 빼먹습니다**(실제 전투는 정상) ⟹ 체력 비례 스킬을 실제보다 약하다고 봅니다 | 체력 비례 항을 예측에 포함. ⚠**실제 피해량은 안 바뀌고 AI 판단만** 바뀝니다 | `fix_hp_ratio.txt` |

⚠`fix_hp_ratio`의 영향 범위 — ~~기본 챔피언 중엔 뱀파이어 정도 + 워크샵 일부~~ → ★**워크샵 챔피언 전용**(0.5.7 정정, 2026-08-28): 게임 0.5.7이 뱀파이어를 전용 이펙트 타입(전용 예측 실구현)으로 이관해 **뱀파이어는 더 이상 이 노브의 영향권이 아닙니다**. 제네릭 AE/AP 예측의 체력 비례 누락 자체는 0.5.7에도 그대로라, 그 경로를 쓰는 워크샵 챔피언에만 유효합니다. (부수: 구 슬롯 상수 18곳이 0.5.6부터 무효라 이 노브는 수개월간 켜도 SKIP되던 상태였고, 2026-08-28에 0.5.7 참값 15곳으로 재배선됨 — RE6-08-28_fix_hp_ratio-0.5.7판정… 참조)
