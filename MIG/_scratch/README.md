# `_scratch/` — 일회용 스크래치 (2026-09-11 분리)

여기 있는 것은 **그때 한 번 쓰고 버린 스크립트**다. 정식 도구가 아니다.

- `_spNN.py` (36) — 명세 배치 작업 중 임시 조회·집계
- `_ai_*.py` (20) — judge 계층 분석 중 임시
- `_nf*.py` / `_perc_*.py` — 이름 매칭·퍼컬레이션 실험분

## 왜 옮겼나
`MIG\` 루트에 `.py` 가 173개까지 늘어 **정식 도구를 못 찾는 상태**가 됐다.
실제 피해: 6차에 네 배치가 `mkpatch.py` 를 **각자 따로 만들었다**(같은 걸 네 번 재발명).
⟹ 루트에는 **정식 도구만** 둔다. 목록 = `TOOLS.md`(자동 생성) · 라우팅 = `METHOD_MAP.md §0`.

## ⚠남겨둔 것 (루트에 있음 — 옮기면 깨진다)
`_dllmatch_lib.py`(`dupmatch.py` 가 import) · `_perc_prep.py`(`percolate.py` 가 import) ·
`_nf2/3/4.py`(서로 import). **load-bearing 이라 이름만 `_` 일 뿐 스크래치가 아니다.**

## 규칙
- 새 일회용 스크립트는 **여기에** 만든다.
- 두 번 이상 쓸 것 같으면 **루트로 올리고 첫 docstring 줄을 쓴 뒤 `mktools.py`** 를 돌린다.
  안 하면 다음 세션이 못 찾고 같은 걸 또 만든다.
