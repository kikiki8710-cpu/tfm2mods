# TFM2 모의 밴픽 도우미 (tfm2_draft_helper)

Teamfight Manager 2 의 밴픽을 도와주는 **독립 실행 도구**.
TFM2.gg 와 같은 "세이브 → 통계 추출 → 소비" 구조를 쓰되, 게임 메모리 후킹 없이
별도 창에서 드래프트를 수동 입력하며 추천을 받는다.

## 사용 흐름
1. 앱을 실행하면 60챔프 그리드 + 추천 패널이 뜬다.
2. 상단 **현재 차례**(내 밴 / 내 픽 / 상대 밴 / 상대 픽)에 맞춰 추천이 갱신된다.
3. 추천 목록의 ⭐1순위 또는 그리드에서 챔프를 **클릭하면 현재 차례 슬롯에 배정**되고 자동으로 다음 차례로 넘어간다.
4. 실제 게임에서 상대가 고른 챔프는 "상대 픽/밴"으로 바꾼 뒤 클릭해 입력한다.
5. 그러면 내 다음 차례 추천이 시너지/카운터까지 반영해 다시 계산된다.
- ↶되돌리기 / ⟲초기화, 상단 슬라이더로 **게임AI ↔ 메타** 비중 조절.

## 추천 엔진 (두 점수를 나란히 표시)
- **게임AI** — 게임 내장 밴픽 AI(`FactoredBanpickAgent`) 의 승률예측 공식 재현
  (10특징 로지스틱 / 베이지안 평활 승률 / 기본가중치 `포지션0.6·시너지0.42·솔로0.15·카운터0.16`).
  단 게임의 feature-hash 테이블 대신 **경기기록 실측 시너지/카운터**를 사용(더 해석가능).
- **메타** — 베이지안 강도점수 `100·(0.7·mean+0.3·lower)` + 드래프트 압력점수 (TFM2.gg 대시보드 식). 티어 OP/1/2/3.
- **종합** = 슬라이더 비중으로 블렌드. 각 추천은 솔로/포지션/시너지/카운터 기여 분해를 보여준다.

## 데이터 (`draft_data.json`)
`export/export_draft_data.py` 가 세이브 디버그 덤프에서 추출:
- `champion_patch_statistics.debug.txt` → 승/픽/밴/포지션별 승률
- `match_replays.debug.txt` → 같은팀 시너지 / 상대 카운터 (직접 집계)
- `champion.i18n` → 한글 이름, `candidate_map.tsv` → 챔프 순서

**데이터 갱신**: TFM2.gg 대시보드의 save_probe 가 최신 세이브로 위 덤프를 갱신한 뒤
`python export/export_draft_data.py` 재실행 → `draft_data.json` 갱신 → exe 옆에 복사.
(게임이 패치돼도 이 추출 단계만 영향받고 앱은 무관.)

## 빌드
```
cargo build --release          # target/release/tfm2_draft_helper.exe (~9MB)
cp draft_data.json target/release/
```
검증(헤드리스): `tfm2_draft_helper.exe --dump` — GUI 없이 샘플 추천을 콘솔 출력.

## 향후 개선 여지
- 세이브의 **학습된** 팀별 밴픽 가중치 추출(현재는 기본가중치+실측통계).
- 포지션 빈자리 인지(이미 채운 라인 제외), 밴 전용 위협-예측 강화.
- 패치별 통계 스코프 선택(현재는 전 패치 합산).
- 인게임 드래프트 화면 자동 인식(오버레이) — 별도 모드로 확장 가능.
