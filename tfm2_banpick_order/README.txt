밴픽 순서 커스텀 (tfm2_banpick_order)
============================================================

밴픽 진행 순서를 원하는 대로 바꾸는 모드입니다.
기본 게임은 "밴 전부 → 픽 전부" 순서만 되지만,
이 모드로 밴과 픽을 섞을 수 있습니다.

  예) 밴 3개씩 → 픽 6개 → 다시 밴 2개씩 → 픽 4개


[ 설치 ]
------------------------------------------------------------

1. 압축을 풀면 tfm2_banpick_order 폴더가 나옵니다.

2. 이 폴더를 게임 설치 폴더의 mods 폴더에 넣습니다.

     Teamfight Manager2\mods\tfm2_banpick_order\

3. 게임을 켜고 모드 목록에서 활성화합니다.


[ 설정 바꾸기 ]
------------------------------------------------------------

mods\tfm2_banpick_order\tfm2_banpick_order.cfg 를 메모장으로 엽니다.
값을 바꾼 뒤에는 게임을 껐다 켜야 적용됩니다.


* 순서 지정

토큰 4가지를 원하는 순서대로 나열하면 됩니다.

     B1  =  1팀(블루) 밴
     B2  =  2팀(레드) 밴
     P1  =  1팀(블루) 픽
     P2  =  2팀(레드) 픽

예시:

  seq_5v5_ban5 = B1 B2 B1 B2 B1 B2 P1 P2 P2 P1 P1 P2 B2 B1 B2 B1 P2 P1 P1 P2

  → 밴 3개씩  →  픽 6개  →  밴 2개씩  →  픽 4개


* 지켜야 할 규칙 3가지

  - B1 개수 = B2 개수 = 게임 설정의 팀당 밴 수
  - P1 개수 = P2 개수 = 팀당 픽 수 (5v5면 5)
  - 마지막은 픽으로 끝나야 함

규칙에 안 맞으면 그 줄만 무시하고 게임 기본 순서로 진행합니다.
(게임이 깨지지는 않습니다.)


* 밴 수가 다른 경기

밴 수별로 여러 줄 적어두면, 경기 설정에 맞는 걸 자동으로 골라 씁니다.

  seq_5v5_ban5 = ...    (팀당 밴 5개인 경기에 적용)
  seq_5v5_ban4 = ...    (팀당 밴 4개인 경기에 적용)

키 이름의 _ban5 는 알아보기 쉬우라고 붙이는 표기이고,
실제로는 B1 토큰 개수로 판단합니다.


[ 밴픽 AI 보정 (선택 기능) ]
------------------------------------------------------------

게임 기본 AI는 밴할 때 이미 뽑힌 챔피언을 전혀 보지 않습니다.
밴과 픽을 섞는 순서에서는 어색하기 때문에 다음 보정을 넣었습니다.

  - 상대 조합과 잘 어울리는 챔피언을 미리 밴
  - 내 조합을 잘 카운터하는 챔피언을 선제 밴

게임 점수를 덮어쓰지 않고 보정치만 더합니다.

  ai_ban_context = 1     (0 = 끄기)
  ai_w_syn = 1.0         상대 조합 시너지 기준 (0 = 이 기준만 끄기)
  ai_w_cnt = 1.0         내 조합 카운터 기준 (0 = 이 기준만 끄기)
  ai_cap   = 1.5         보정 상한 (클수록 강하게 개입)

다른 밴픽 AI 모드를 쓰신다면 ai_ban_context = 0 으로 꺼주세요.
같은 방식으로 동작하기 때문에 둘 다 켜면 보정이 겹칩니다.
(순서 기능은 이 값과 상관없이 계속 동작합니다.)


[ 참고 ]
------------------------------------------------------------

- 순서를 바꾼 뒤로는 그 전에 저장된 다시보기의
  밴픽 결과가 달라질 수 있습니다.

- 문제가 생기면 enabled = 0 으로 끄면
  게임 기본 동작으로 돌아갑니다.

- Windows 전용입니다.
