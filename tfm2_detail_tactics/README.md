# 상세전술 0.1.0

게임 0.6.5 전용. 팀전술 화면의 **상세전술** 버튼에서 포지션별 또는 팀 공통으로 기본/낮게/높게를 선택합니다. 전술 32개 중 26개(42지점)를 지원합니다. 나머지 6개는 창에 ‘이번 버전 미지원’으로 표시하고 원래 동작을 유지합니다.

- 칸을 누르면 기본 → 낮게 → 높게로 전환합니다. 켬/끔 전술은 기본 → 끔입니다.
- **확인**: 내 팀에 적용하고 현재 세이브에 저장합니다. **취소**: 이번 창에서 편집한 내용을 버립니다.
- ‘전부 기본으로’를 누른 뒤 확인하면 원래 전술로 돌아갑니다.
- `detail_tactics_values.cfg`의 ‘낮게’/‘높게’ 숫자를 고치면 약 120프레임 이내에 다시 읽습니다. 예: `[combat_retreat_hp]`의 `낮게 = 15`, `높게 = 60`.
- 상대 팀은 변경하지 않습니다. 판단 중인 선수의 64비트 선수 ID를 내 팀 계약 명단과 대조합니다.
- EXE 신원/지점 바이트가 다르거나 한 전술의 일부 지점만 설치되면 그 전술은 원본을 유지합니다.
- `tfm2_ai_analysis_verify`, `tfm2_tactics_verify`가 로드된 실행에서는 적용 장치를 설치하지 않습니다.

## 빌드 및 설치

`build_local.ps1 -RunTests`로 테스트와 로컬 DLL 빌드를 실행합니다. `package_local.ps1`은 기본 설정/설명서를 포함한 설치용 ZIP을 `target/package/`에 만듭니다. 게임 폴더에는 직접 복사하지 않습니다.

설치는 `install.ps1 -GameDir '<게임 설치 경로>'`를 실행합니다. 게임 실행 중에는 설치를 거절합니다. 기존 값 설정 파일은 보존합니다. 모드 관리에서 상세전술을 활성화한 뒤 게임을 재시작하세요.

로그는 `mods/_log_root.txt`의 지정 폴더(없으면 모드 폴더)에 `detail_tactics.log`로 기록합니다. 지점별 calls/mine/applied와 선수 ID·팀·포지션 표본을 확인할 수 있습니다.

## 검증 범위

검증 기록 정본은 작업 공간의 `mods_report/tfm2_detail_tactics/02_구현정보.md`입니다. 자동 검사와 실제 인게임 검수는 구분해서 기록합니다.
