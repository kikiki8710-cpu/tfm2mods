# 상세전술 0.2.3

게임 0.7.0 전용. 팀전술 화면의 **상세전술** 버튼에서 포지션별 또는 팀 공통으로 기본/낮게/높게를 선택합니다. 상세전술 창에는 총 59개를 표시합니다.

0.2.3은 게임 0.7.0 대응판입니다. 0.7.0에서 바뀐 판단 지점을 다시 연결했습니다. **로밍 최소 자기 체력**, **로밍 팀 콜 확률**, **로밍 재시도 추가 간격** 3개는 뺐습니다. 0.7.0에 새로 생긴 선수 특성(상대 정글 침투)이 같은 판단 지점을 쓰기 때문에, 라인 로밍용 값이 상대 정글 침투에 섞일 수 있어서입니다. 예전 세이브에 이 3개를 설정해 두었어도 적용하지 않고 원래 게임대로 동작합니다.

0.2.2에서는 구매 귀환 도보시간·위협 반경·위협 기억, 같은 라인 동료 근접반경, 지원 순평가 0 대체 감점, 라인 기회 상대 수 상한을 **라인·이동**에 추가했습니다. 일반 캠프 기한 비교 도착 여유는 **정글**, 아군 전원의 상대 기지 근접 반경과 매복 대기 인정 반경은 **갱·로밍**, 등록 추적대상 추격 가산과 궁극기 낭비 억제 감점은 **전투·생존**, 기술 도달 예측 여유는 **위치·기술**에 있습니다. 정글 전용 항목은 정글 칸에만 표시합니다. 각 탭에서 스크롤해 선택할 수 있으며 새 항목은 모두 기본값으로 시작합니다. 다시보기 결과 변화는 승률 향상 판정이 아닙니다.

0.2.1은 두 경기의 다시보기 비교에 따라 추가 전술의 표시 범위를 정리했습니다. 앞서 변화가 확인된 13개를 유지하고 처치 가산점 상한·교전 참조 역할 표시수·보스 사냥 재배치 개선값·이동기 절약 보행 여유 4개를 포함합니다. 나머지 39개는 창에서 숨깁니다. 저장 ID와 기존 선택값은 보존되므로 숨긴 항목에 저장된 설정도 계속 적용됩니다. ‘전부 기본으로’는 숨긴 항목을 포함한 88개 전체를 초기화합니다. 결과가 같았다는 이유만으로 효과 없음으로 확정한 것은 아닙니다.

0.2.0은 정적 연결을 확보한 56개 전술을 추가합니다. 전투·생존 / 라인·이동 / 정글 / 갱·로밍 / 푸시·타워 / 기지 방어 / 오브젝트 / 위치·기술의 8개 탭으로 분류하며 각 탭은 스크롤됩니다. 제목과 확인·취소 버튼은 고정되고, 탭을 옮겨도 편집 내용과 각 탭의 스크롤 위치를 유지합니다. 기존 32개 저장 ID와 설정값을 보존하며 새 항목은 기본 단계로 시작합니다.

여러 문턱이 묶인 항목은 설명에 적힌 기준값을 함께 조정합니다. 시간은 원래 시뮬레이션 TPS로, 거리는 원래 정수 거리식으로 환산합니다. 실제 스킬의 사거리나 승인 규칙을 강제로 건너뛰지 않습니다. ‘기본’은 원본 명령으로 우회합니다. 선수·호출자 확인 실패와 설정 갱신 중인 판정도 원본으로 돌아갑니다.

0.1.8에서는 풀다운 선택값과 펼쳐진 목록의 항목 글자를 칸 가운데로 정렬했습니다. 선수별·팀 공통·원딜/서폿 통합 칸에 모두 적용됩니다.

0.1.7에서는 페이지를 없애고 **전투·생존 / 라인·이동 / 정글 / 갱·로밍 / 푸시·타워 / 기지 방어** 탭으로 묶었습니다. 탭을 옮겨도 편집 내용이 유지되며 확인·취소는 모든 탭에 적용됩니다. 정글 전용 4종, 정글을 제외한 로밍 3종, 서폿 미니언 처리, 탑·미드·원딜 라인 배정은 해당 포지션 칸만 표시합니다. 정글링 중단의 이름과 캠프 안전 반경·갱 콜 수락 설명도 실제 적용 조건에 맞췄습니다.

0.1.6에서는 원딜·서폿 짝 동행 확인을 두 포지션 칸에 걸친 풀다운 하나로 합쳤습니다. 선택하면 원딜·서폿 설정을 함께 바꿉니다. 이전 저장의 두 값이 다르면 재선택 안내를 표시하며, 새로 선택하기 전에는 기존 값을 보존합니다.

0.1.5에서는 포지션 제목을 가운데 정렬하고, 설정 칸을 풀다운 선택 방식으로 바꿨습니다.

0.1.4에서는 남은 **갱 중 적 포탑 교전 시 포기**, **정글링·로밍 중단 체력**, **라인 배정 체력**, **원딜·서폿 짝 동행 확인**을 복구했습니다. 라인 배정 체력은 검사받는 후보 선수의 설정을 읽으며, 원래 체력 검사 대상인 탑·미드·원딜에 적용됩니다. 현재 경기 캐시의 캐릭터·선수 대응 및 호출자가 보존한 선수 포인터로 판단자를 확인하며, 상대 팀이나 다른 경기의 같은 색 팀에는 설정을 적용하지 않습니다.

- 칸의 풀다운 목록에서 기본/낮게/높게를 직접 선택합니다. 켬/끔 전술은 기본·켬/끔 두 항목입니다. 목록 바깥을 클릭하면 닫힙니다.
- **확인**: 내 팀에 적용하고 현재 세이브에 저장합니다. **취소**: 이번 창에서 편집한 내용을 버립니다.
- 게임의 **저장하기** 또는 자동 저장이 이루어져야 선택이 세이브 파일에도 보존됩니다.
- ‘전부 기본으로’를 누른 뒤 확인하면 원래 전술로 돌아갑니다.
- `detail_tactics_values.cfg`의 ‘낮게’/‘높게’ 숫자를 고치면 약 120프레임 이내에 다시 읽습니다. 예: `[combat_retreat_hp]`의 `낮게 = 15`, `높게 = 60`.
- 상대 팀은 변경하지 않습니다. 판단 중인 선수의 64비트 선수 ID를 내 팀 계약 명단과 대조합니다.
- EXE 신원/지점 바이트가 다르거나 한 전술의 일부 지점만 설치되면 그 전술은 원본을 유지합니다.
- `tfm2_ai_analysis_verify`, `tfm2_tactics_verify`가 로드된 실행에서는 적용 장치를 설치하지 않습니다.
- 게임 시작 중 스레드 목록이 달라지면 정지 전에 최대 32회 다시 확인합니다. 핸들 준비 후 스레드가 종료되는 등 일시 경쟁은 정지한 스레드를 모두 재개한 뒤 최대 16회 장벽을 새로 구성합니다. 코드 쓰기·게이트 게시를 반복하지 않으며, 열거 오류·재개 실패·재시도 한도 초과는 원본으로 돌아갑니다.

## 빌드 및 설치

`build_local.ps1 -RunTests`로 테스트와 로컬 DLL 빌드를 실행합니다. `package_local.ps1`은 기본 설정/설명서를 포함한 설치용 ZIP을 `target/package/`에 만듭니다. 게임 폴더에는 직접 복사하지 않습니다.

설치는 `install.ps1 -GameDir '<게임 설치 경로>'`를 실행합니다. 게임 실행 중에는 설치를 거절합니다. 기존 값 설정 파일은 보존합니다. 모드 관리에서 상세전술을 활성화한 뒤 게임을 재시작하세요.

로그는 `mods/_log_root.txt`의 지정 폴더(없으면 모드 폴더)에 `detail_tactics.log`로 기록합니다. 지점별 calls/mine/applied와 선수 ID·팀·포지션 표본을 확인할 수 있습니다.

## 검증 범위

검증 기록 정본은 작업 공간의 `mods_report/tfm2_detail_tactics/02_구현정보.md`입니다. 자동 검사와 실제 인게임 검수는 구분해서 기록합니다.

0.1.7은 Rust 테스트 27개를 통과했습니다. 실제 게임에서 6개 탭·적용 포지션 표시·풀다운·탭 간 편집 유지·확인 후 재열기·전체 초기화 후 취소를 확인했습니다. 이번 검수는 경기 시작 전 UI와 세이브 데이터 기록까지이며, 별도 파일 저장·재로드나 경기 행동 효과를 다시 측정하지 않았습니다.

0.1.4 이전에는 x64 실행 비교 9,540건과 당시 4페이지 UI, 후퇴 체력/서폿 미니언 처리/푸시 유지의 실제 적용을 확인했습니다. 지원하는 모든 전술의 승률 효과를 검증한 것은 아닙니다.
