모드 목록 순서 변경 (Mod List Reorder) v0.2.0 — 설치 안내 (게임 0.6.0)
============================================================

■ 설치
1) 이 zip 안의 tfm2_mod_order 폴더를 통째로 아래 위치에 넣습니다.
   <게임 설치폴더>\Teamfight Manager2\mods   → 최종 경로: ...\Teamfight Manager2\mods	fm2_mod_order   (폴더 안에 tfm2_mod_order.dll 과 mod.mod_info 가 있어야 합니다.)
2) 게임 실행 → 모드 관리에서 "모드 목록 순서 변경" 활성화 (코드 모드 경고 수락).
3) 게임을 재시작하면 적용됩니다.

■ 사용법 (타이틀 → 모드 관리 화면에서)
· 행 클릭 또는 ↑ / ↓ : 모드 선택 (선택된 행의 배경이 강조됩니다)
· Ctrl + ↑ / ↓        : 선택한 모드를 위/아래로 이동 (즉시 저장)
· 키를 꾹 누르면 잠시 후 한 칸씩 연속 이동
· ※ 0.6.0 판은 자동 스크롤이 없습니다 — 선택이 화면 밖이면 마우스 휠로 스크롤하세요.

■ 순서 저장
· 바꾼 순서는 mods	fm2_mod_order\mod_order.txt 에 자동 저장되어 다음에 켜도 유지됩니다.
· 이 모드를 끄면 게임 기본 순서(mod_id 폴더명 알파벳순)로 표시됩니다.
· mod_order.txt 를 직접 편집해도 됩니다(행당 mod_id 1개, 위→아래, # 은 주석).

■ 안전성
· 게임 함수를 후킹하지 않는 순수 stable SDK 모드입니다(하드코딩 주소 없음).
· 순서 변경은 모드 관리 화면 표시에만 영향을 주며, 게임 플레이/세이브에는 영향이 없습니다.
· 게임 0.6.0 전용(0.6.1 이상에서는 자동 비활성 — 새 버전 zip 을 받으세요).
