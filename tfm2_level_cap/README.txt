===============================================================================
 Champion Level Cap (tfm2_level_cap)
 경기 중 챔피언 최대 레벨을 12에서 원하는 값으로 확장하는 모드
 대상 게임 버전: Teamfight Manager 2  0.5.3
===============================================================================

■ 이 모드가 하는 일

  바닐라 게임은 경기 중 챔피언이 최대 12레벨까지만 오릅니다.
  이 모드는 그 상한을 원하는 레벨까지 늘려줍니다(기본 18레벨).

  레벨 12까지 필요한 경험치는 바닐라와 완전히 동일합니다.
  13레벨부터의 필요 경험치만 설정 파일에서 정합니다.

  스탯은 원래 게임과 같은 방식으로 레벨당 일정량씩 오릅니다.
  (레벨이 높아질수록 챔피언이 그만큼 강해집니다)


-------------------------------------------------------------------------------
■ 설치 방법
-------------------------------------------------------------------------------

  1) 게임 설치 폴더를 엽니다.

     Steam 라이브러리에서 Teamfight Manager 2 를 마우스 오른쪽 클릭
      → 관리 → 로컬 파일 보기

     보통 아래 경로입니다:
     C:\Program Files (x86)\Steam\steamapps\common\Teamfight Manager2\

  2) 그 폴더 안의 mods 폴더로 들어갑니다.
     (mods 폴더가 없다면 새로 만드세요)

  3) 받은 압축 파일을 mods 폴더 안에 풉니다.

     압축 안에 tfm2_level_cap 폴더가 들어 있으므로,
     mods 폴더에 그대로 풀면 됩니다.

     ※ 폴더 이름(tfm2_level_cap)은 절대 바꾸지 마세요. 게임이 인식하지 못합니다.


-------------------------------------------------------------------------------
■ 압축을 푼 뒤 파일 구조
-------------------------------------------------------------------------------

  Teamfight Manager2\
   └─ mods\
       └─ tfm2_level_cap\
           ├─ mod.mod_info          (모드 정보 - 건드리지 마세요)
           ├─ mod.override_info     (모드 정보 - 건드리지 마세요)
           ├─ tfm2_level_cap.dll    (모드 본체 - 건드리지 마세요)
           └─ tfm2_level_cap.cfg    ★설정 파일 - 여기만 수정합니다

  게임을 한 번 실행하면 같은 폴더에 tfm2_level_cap.txt(기록 파일)가
  자동으로 생깁니다. 문제가 생겼을 때 원인을 확인하는 용도이며,
  지워도 다음 실행 때 다시 만들어집니다.


-------------------------------------------------------------------------------
■ 게임에서 모드 켜기  ★이 단계를 빠뜨리면 아무 일도 일어나지 않습니다
-------------------------------------------------------------------------------

  압축을 푸는 것만으로는 적용되지 않습니다.
  게임을 실행한 뒤 모드 관리 화면에서 "Champion Level Cap"을 켜 주세요.

  켠 다음에는 게임을 완전히 종료했다가 다시 실행해야 적용됩니다.

  ※ 모드를 새 버전으로 교체하면 목록에서 꺼질 수 있습니다.
     업데이트한 뒤에는 켜져 있는지 한 번 확인해 주세요.


-------------------------------------------------------------------------------
■ 설정 변경 방법
-------------------------------------------------------------------------------

  tfm2_level_cap.cfg 파일을 메모장으로 열어 수정합니다.

  ┌───────────────────────────────────────────────────────────────┐
  │ 18                                                            │  ← 1줄: 최대 레벨
  │ 2700,3000,3300,3600,3900,4200                                 │  ← 2줄: 필요 경험치
  └───────────────────────────────────────────────────────────────┘

  · 1번째 줄 = 최대 레벨 (2 ~ 500 사이)

  · 2번째 줄 = 12→13 레벨부터 필요한 경험치를 쉼표(,)로 구분해 나열
               (12레벨까지는 바닐라 값이므로 적지 않습니다)

  · # 으로 시작하는 줄과 빈 줄은 설명으로 취급해 무시합니다.
    원하는 만큼 메모를 남겨도 됩니다.

  수정한 뒤에는 게임을 다시 시작해야 적용됩니다.


  [ 적어야 하는 경험치 개수 ]

    필요 개수 = 최대 레벨 - 12

    예) 최대 레벨 18 → 6개 (12→13, 13→14, 14→15, 15→16, 16→17, 17→18)
        최대 레벨 20 → 8개
        최대 레벨 15 → 3개

    개수가 딱 맞지 않아도 됩니다:

      · 더 많이 적으면  → 필요한 개수까지만 쓰고 나머지는 버립니다.
      · 모자라게 적으면 → 마지막에 적은 값으로 남은 레벨을 모두 채웁니다.


  [ 설정 예시 ]

    · 18레벨, 후반으로 갈수록 점점 많이 필요 (기본값)
        18
        2700,3000,3300,3600,3900,4200

    · 20레벨, 13레벨부터는 전부 3000씩 (한 개만 적으면 나머지가 다 채워집니다)
        20
        3000

    · 30레벨, 아주 쉽게 올라가는 설정
        30
        500

    · 15레벨, 한 단계씩 직접 지정
        15
        2000,2500,3000

    · 바닐라 그대로 되돌리기 (모드를 끄는 것과 같은 효과)
        12
        0

■ 문제가 생겼을 때
-------------------------------------------------------------------------------

  · 레벨이 12에서 그대로예요
      → 게임 모드 화면에서 모드가 켜져 있는지 확인하세요.
      → 켠 뒤 게임을 완전히 껐다가 다시 켰는지 확인하세요.
      → tfm2_level_cap.txt 파일을 열어 [cfg] 와 [hook] 줄을 확인하세요.
        hooked 라고 적혀 있으면 정상 설치된 것입니다.

  · 설정을 바꿨는데 반영이 안 돼요
      → 게임을 완전히 종료했다가 다시 실행해야 합니다.
      → tfm2_level_cap.txt 의 [cfg] 줄에 해석 결과가 그대로 찍히므로,
        내가 적은 값이 제대로 읽혔는지 확인할 수 있습니다.
      → 설정 값이 잘못되면 기본값으로 되돌아가며, 그 이유도 함께 적힙니다.

  · 모드를 끄고 싶어요
      → 게임 모드 화면에서 끄면 됩니다.
      → 완전히 지우려면 tfm2_level_cap 폴더를 통째로 삭제하세요.

  · 게임이 튕겨요
      → tfm2_level_cap 폴더의 tfm2_level_cap.dll 파일 이름을 바꾸거나
        폴더를 삭제하면 모드 없이 실행됩니다.


-------------------------------------------------------------------------------
■ 알아두실 점
-------------------------------------------------------------------------------

  · 이 게임은 경기를 다시 계산하는 방식이라, 모드를 켜면 경기 결과가
    바닐라와 달라집니다. 기존 세이브에 적용해도 되지만 진행 중이던
    경기의 결과는 이전과 다르게 나올 수 있습니다.

  · 최대 레벨을 지나치게 높이면 챔피언 스탯이 계속 올라가 경기 밸런스가
    크게 무너집니다. 처음에는 18~20 정도로 시작해 보시길 권합니다.

  · 이 버전은 게임 0.5.3 전용입니다. 게임이 0.5.4 이상으로 업데이트되면
    모드가 자동으로 꺼집니다(잘못된 버전에서 튕기는 것을 막기 위해서입니다).
    그때는 레벨이 12로 돌아갑니다. 새 버전을 기다려 주세요.
    ※ 그 밖의 이유로 동작하지 않을 때는 tfm2_level_cap.txt 에
      [hook] 실패 기록이 남습니다.
