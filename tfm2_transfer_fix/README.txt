===============================================================================
 Transfer & Salary Fix (tfm2_transfer_fix)
 0.7.0 이적료·연봉 폭등을 만드는 계산 오류 3가지를 바로잡는 모드
 대상 게임 버전: Teamfight Manager 2  0.7.0 (모드 v0.1.0)
===============================================================================

■ 이 모드가 하는 일

  0.7.0 에서 이적 시스템이 새로 짜이면서, 이적료와 연봉이 비정상으로 높게 나오는
  계산 오류가 생겼습니다. 이 모드는 그중 세 가지를 바로잡습니다.

  ① AI 가 선수를 팔 때 부르는 값(= 「예상 이적료」)에 항상 2.59배 이상이 붙던 것
     → 시장 상황에 따라 보통 1.25배 안팎으로 붙도록 고칩니다.
       (같은 값이 협상 바닥가와 재계약 요구액의 일부에도 쓰여 함께 내려갑니다)

  ② 첫 시즌이 끝날 때(1월 1일) 연봉 보정이 같은 해 값으로 두 번 곱해지던 오류
     → 한 번만 곱해지도록 고칩니다.

  ③ 연봉·선수가치 배율이 해마다 상한 없이 누적되던 것
     → 기본 0.8배 ~ 2.0배 안으로 묶습니다(설정에서 조절).
       이미 배율이 크게 부푼 세이브도 이 범위로 잘려서 적용됩니다.

  ※ 바뀌는 것은 「앞으로 계산되는 값」입니다. 이미 맺은 계약의 연봉은 그대로입니다.
  ※ 17세 유망주에게 수십억 이적료가 붙는 일부 사례는 원인이 아직 다 밝혀지지 않아,
     이 모드로 2.59배 몫만 줄어듭니다.


-------------------------------------------------------------------------------
■ 설치 방법
-------------------------------------------------------------------------------

  1) 게임 설치 폴더의 mods 폴더를 엽니다.
     (Steam 라이브러리 → Teamfight Manager 2 오른쪽 클릭 → 관리 → 로컬 파일 보기)

  2) 압축 안의 tfm2_transfer_fix 폴더를 mods 폴더에 그대로 풉니다.
     ※ 폴더 이름(tfm2_transfer_fix)은 바꾸지 마세요.

  3) 게임을 켜고 모드 메뉴에서 이 모드를 켠 뒤, 게임을 다시 시작합니다.


-------------------------------------------------------------------------------
■ 파일 구조
-------------------------------------------------------------------------------

  mods\
   └─ tfm2_transfer_fix\
       ├─ mod.mod_info             (모드 정보 - 건드리지 마세요)
       ├─ tfm2_transfer_fix.dll    (모드 본체 - 건드리지 마세요)
       └─ tfm2_transfer_fix.cfg    ★설정 파일 (처음 실행할 때 자동으로 생깁니다)

  실행하면 같은 폴더에 tfm2_transfer_fix.txt(기록 파일)가 생깁니다.
  첫 줄 근처의 [selfcheck] 가 PASS 면 정상 적용된 것입니다.


-------------------------------------------------------------------------------
■ 설정 (tfm2_transfer_fix.cfg) — 고친 뒤 게임을 다시 켜야 적용
-------------------------------------------------------------------------------

  spread_floor_fix = 1      ① 호가 하한 제거 (0 이면 바닐라)
  spread_c = 0.95           호가 폭 기준값 (바닐라와 같은 0.95 권장)
  spread_default = 0.23     비교할 시장 표본이 없을 때의 호가 폭 (0.23 = 1.26배)
  double_apply_fix = 1      ② 이중 적용 수정 (0 이면 바닐라)
  salary_mult_clamp = 1     ③ 배율 제한 (0 이면 바닐라 = 제한 없음)
  salary_mult_min = 0.8     배율 하한
  salary_mult_max = 2.0     배율 상한


-------------------------------------------------------------------------------
■ 주의
-------------------------------------------------------------------------------

  · 게임 0.7.0 전용입니다. 게임이 업데이트되면 [selfcheck] FAIL 이 뜨고
    아무것도 바꾸지 않은 채(바닐라 동작) 넘어갑니다. 새 버전용으로 갱신될 때까지 기다려 주세요.
  · 모드를 끄면 바로 바닐라 계산으로 돌아갑니다(세이브에 따로 남기는 값 없음).
