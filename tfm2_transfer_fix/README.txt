===============================================================================
 Transfer & Salary Fix (tfm2_transfer_fix)
 이적료·연봉 폭등을 만드는 문제 2가지를 바로잡는 모드
 대상 게임 버전: Teamfight Manager 2  0.7.1 (모드 v0.2.2)
===============================================================================

■ 이 모드가 하는 일

  0.7.0 에서 이적 시스템이 새로 짜이면서, 이적료와 연봉이 비정상으로 높게 나오는
  계산 문제가 생겼습니다. 이 모드는 그중 두 가지를 바로잡습니다.

  ① AI 가 선수를 팔 때 부르는 값(= 「예상 이적료」)에 항상 2.59배 이상이 붙던 것
     → 시장 상황에 따라 보통 1.25배 안팎으로 붙도록 고칩니다.
       (같은 값이 협상 바닥가와 재계약 요구액의 일부에도 쓰여 함께 내려갑니다)

  ② 연봉·선수가치 배율이 해마다 상한 없이 누적되던 것
     → 안전 상한을 둡니다. 기본 5.0배 = 평소엔 거의 걸리지 않고, 폭주할 때만 자릅니다.
       ①과 달리 게임의 계산 실수가 아니라 「상한이 없는 설계」라서, 게임 계산을
       최대한 그대로 두도록 넉넉하게 잡았습니다.
       ★플레이하다가 연봉·이적료가 너무 많이 오른다 싶으면 설정의 salary_mult_max 를
         낮추세요(예: 3.0, 더 세게는 2.0). 이미 부푼 세이브에도 바로 적용됩니다.

  ※ 바뀌는 것은 「앞으로 계산되는 값」입니다. 이미 맺은 계약의 연봉은 그대로입니다.
  ※ 17세 유망주에게 수십억 이적료가 붙는 일부 사례는 원인이 아직 다 밝혀지지 않아,
     이 모드로 2.59배 몫만 줄어듭니다.
  ※ 두 가지 모두 실제 게임(0.7.0)에서 첫 연도 전환(1월 1일)을 넘기며 작동을 확인했습니다.
  ※ 0.7.0 판에 있던 「연봉 보정 이중 적용 수정」은 0.7.1 에서 게임이 직접 고쳐서 v0.2.2 에서 뺐습니다.


-------------------------------------------------------------------------------
■ 언제 넣어야 하나 (세이브 상태별)
-------------------------------------------------------------------------------

  · 아무 때나 넣으면 됩니다. ①과 ②는 넣는 순간부터 적용됩니다.

  · 어느 경우든 이미 맺은 계약의 연봉과 끝난 이적은 바뀌지 않고,
    재계약·새 계약부터 바뀐 계산이 적용됩니다.


-------------------------------------------------------------------------------
■ 설치 방법
-------------------------------------------------------------------------------

  1) 게임 설치 폴더의 mods 폴더를 엽니다.
     (Steam 라이브러리 → Teamfight Manager 2 오른쪽 클릭 → 관리 → 로컬 파일 보기)

  2) 압축 안의 tfm2_transfer_fix 폴더를 mods 폴더에 그대로 풉니다.
     ※ 폴더 이름(tfm2_transfer_fix)은 바꾸지 마세요.

  3) 게임을 켜고 모드 메뉴에서 이 모드를 켠 뒤, 게임을 다시 시작합니다.


-------------------------------------------------------------------------------
■ 파일 구조
-------------------------------------------------------------------------------

  mods\
   └─ tfm2_transfer_fix\
       ├─ mod.mod_info             (모드 정보 - 건드리지 마세요)
       ├─ tfm2_transfer_fix.dll    (모드 본체 - 건드리지 마세요)
       └─ tfm2_transfer_fix.cfg    ★설정 파일 (처음 실행할 때 자동으로 생깁니다)

  실행하면 같은 폴더에 tfm2_transfer_fix.txt(기록 파일)가 생깁니다.
  첫 줄 근처의 [selfcheck] 가 PASS 면 정상 적용된 것입니다.


-------------------------------------------------------------------------------
■ 설정 (tfm2_transfer_fix.cfg) — 고친 뒤 게임을 다시 켜야 적용
-------------------------------------------------------------------------------

  spread_floor_fix = 1      ① 호가 하한 제거 (0 이면 바닐라)
  spread_c = 0.95           호가 폭 기준값 (바닐라와 같은 0.95 권장)
  spread_default = 0.23     비교할 시장 표본이 없을 때의 호가 폭 (0.23 = 1.26배)
  salary_mult_clamp = 1     ② 배율 상한 (0 이면 바닐라 = 제한 없음)
  salary_mult_max = 5.0     배율 상한 ★너무 오른다 싶으면 낮추세요(3.0 → 2.0)
  salary_mult_min = 0       배율 하한 (0 = 없음 · 낮은 연봉이 너무 떨어질 때만 예: 0.8)

  참고로 0.7.0 첫 연도 전환 직후 배율은 0.67 ~ 1.85 였습니다(2026-11 실측).
  상한을 2.0 아래로 내리면 평범한 상위 선수까지 깎이기 시작합니다.

  ※ v0.1.0 에서 업데이트하는 경우: 설정 파일은 이미 만들어져 있어서 예전 기본값
     (하한 0.8 · 상한 2.0)이 그대로 남습니다. 새 기본값을 쓰려면 tfm2_transfer_fix.cfg 를
     지우고 게임을 켜면 새로 만들어집니다(또는 위 두 값을 직접 고치세요).
  ※ 예전 설정 파일에 double_apply_fix 줄이 남아 있어도 무시되니 그대로 두어도 됩니다.
