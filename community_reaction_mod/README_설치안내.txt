community_reaction_mod — 게임 0.6.0 대응 패치 (stable ABI 재작성판)
=====================================================================

[중요] 설치 위치
-----------------
이 모드는 스팀 창작마당(워크샵) 구독 모드입니다.
따라서 이 zip은 게임의 mods 폴더가 아니라, 워크샵 폴더에 덮어써야 합니다.

  덮어쓸 곳:
  ...\Steam\steamapps\workshop\contentÀ9300û8958482
  (zip 안의 community_reaction_mod 폴더 내용물을 위 폴더에 덮어쓰기)

※ 게임의 mods 폴더에 풀면 아무 일도 일어나지 않습니다.
   (이 zip에는 mod.mod_info가 없어 게임이 별도 모드로 인식하지 않습니다.
    워크샵본과 중복 등록되는 것을 막기 위해 일부러 제외했습니다.)

※ 작업 전에 게임을 완전히 종료하세요. 실행 중이면 dll이 잠겨 복사가 실패합니다.
※ 적용하려면 게임을 완전히 재시작해야 합니다.
※ 이 판은 게임 0.6.0 전용입니다(0.6.1 이상에서는 자동 비활성 — 새 zip을 받으세요).


변경 사항
---------
1. 게임 0.6.0 대응 — 공식 stable 모드 API로 전면 재작성
   - 0.6.0부터 예전 방식(클래식 SDK) 모드는 로드되지 않아 새 API로 다시 만들었습니다.
   - 경기 데이터 조립을 서버 쪽으로 옮겼고, 결과 파일(latest_match.js)은 이제
     갤러리 HTML과 같은 폴더(워크샵 폴더)에 생깁니다.

2. 경기 하이라이트 복구 (2026-09-20)
   - 관전·리플레이한 세트의 연속킬 / 다인 궁·광역기 / 포탑 데스 / 골드 대역전이
     "--- 경기 하이라이트 ---" 섹션으로 다시 나옵니다.
   - 골드 열세 판정은 누적 획득 골드 기준으로 바뀌어 초반 헛 "역전승"이 사라졌습니다.

3. 갤러리(TFA2_gallery.html)
   - Cerebras 기본 모델을 gpt-oss-120b로 변경(기존 gemma-4-31b는 서비스 종료 → 404).
     선택지: gpt-oss-120b / qwen-3.8-27b / 직접 입력. 저장돼 있던 옛 모델명은 자동 치환됩니다.
   - Cerebras는 이제 30일 무료 체험만 제공합니다. 무료로 쓰려면 설정에서
     "Google Gemini"를 선택하고 AI Studio 키를 넣으세요(gemini-3.5-flash 등 무료 티어).
   - 모델을 찾을 수 없을 때(404) 무엇을 고쳐야 하는지 안내가 뜹니다.


포함 파일
---------
  community_reaction_mod.dll   본체 (0.6.0 stable)
  TFA2_gallery.html            갤러리 화면

   이 파일을 덮어써도 기존 설정은 그대로 유지됩니다.
